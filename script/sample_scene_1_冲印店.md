# 样场剧本：暗房

## 第52场 - 柯达冲印店暗房 - 内 - 日 - 1982年8月17日

> **人物**: 明仔 (17), 师傅 (60)
> **时长**: 5分钟，全片核心惊悚场面，零血腥

---

**黑屏。**

只有声音：空调嗡鸣，街外车声，远处收音机。

**字幕**: 1982年8月17日 下午3:22 尖沙咀柯达冲印店

**内景 冲印店 - 日**

狭小。墙上贴满样片：全家福、BB相、婚纱。风扇转。

明仔在柜台写单。林过云进来，瘦，戴眼镜，手里一卷菲林，用报纸包着。

```
林过云
(轻声，客气)
晒相。36格。

明仔
(头也不抬，熟练)
光面定绒面？几R？

林过云
光面。全部。

明仔开单：NO. 082-0717

明仔
听日下昼三点后攞。
```

林过云点头，离开。门铃响。

师傅从里间出来，抽烟。

```
师傅
咩人？

明仔
普通客。

师傅
(看了一眼菲林，皱眉)
呢卷菲林...过期咗？

明仔没在意，放进待冲洗篮。
```

**切入：暗房**

红光。狭小，药水味。

明仔把菲林装进暗袋，卷进显影罐。摇晃。计时。

水声。秒针滴答。

他把相纸放进放大机。第一张。

**红光下，影像慢慢浮现。**

一张笑容。阿心，17岁，穿校服，比耶。背景是海。

明仔笑了一下，自言自语：

```
明仔
几靓女。
```

第二张。放大机调焦。

影像浮现，慢。明仔的笑容凝固。

我们**不展示**照片内容。只拍明仔的脸。

红光映在他脸上，汗。他的手开始抖。

第三张。他不敢放相纸了，直接看底片，对着红灯。

底片上，黑色的人形。

**声音设计**：放大机的风扇声突然变大，像电锯。

明仔后退一步，撞到药水盘。显影液洒在地上，红色的水。

他冲出暗房。

**冲印店 - 日 - 连续**

师傅在吃饭，叉烧饭。

明仔脸色煞白，手里攥着湿淋淋的底片。

```
明仔
师傅...你睇下...

师傅接过，对着光。沉默。

筷子掉在地上。

师傅 (轻声)
...报警。
```

**两人对视。**

店外，蝉鸣，车声，1982年夏天的日常。

但暗房里，红灯还亮着，药水还在滴。

**切黑。**

**声音延续**：电话拨号声，嘟...嘟...

---

### 导演备注

1.  **镜头**: 全程用 50mm 固定镜头，暗房戏用微距拍药水气泡、相纸纤维，不拍照片内容。恐怖来自明仔的反应，而非奇观。
2.  **表演**: 明仔从轻松到恐惧的转变，要在10秒内完成，无台词。
3.  **声音**: 第二张照片浮现时，加入极低频 (30Hz) 嗡鸣，观众生理不适，但不知道为什么。
4.  **伦理**: 此场戏已请前冲印店职员做顾问，还原1982年真实冲印流程。底片道具为虚构摆拍，不含任何真实受害者影像。
