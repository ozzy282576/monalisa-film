# 档案肖像来源

`elizabeth_short_archival.jpg` 是从 FBI 档案网站所展示的洛杉矶警方调查通告中裁出的肖像，不是 AI 生成人像。

- 原通告：Special Daily Police Bulletin，1947年1月21日。
- 标题：Wanted Information on Elizabeth Short — Between Dates January 9 and 15, 1947。
- 来源：[FBI Archives — LAPD Bulletin on Elizabeth Short](https://archives.fbi.gov/archives/news/stories/2006/october/lapd-seeking-information-poster-on-elizabeth-short)。
- 从已读取的500×639通告图片裁切 `(125,178)–(392,474)`，仅裁切和常规JPEG保存，未使用生成模型修改人脸。
- 成片中标明“档案照片”，与其他AI情景重现镜头区分。

替换原因：实际生成的S09人像外观偏成熟，不适合用于明确呈现22岁的受害者身份；原生成记录和抽样检查图仍保留，未伪称其已通过角色准确性审核。

通告正文中可直接读出她于1月9日在Biltmore下车、随后进入大堂，警方征集1月9日至15日期间的行踪线索。该图片用于事实核查与身份介绍，不把通告理解为受害者的犯罪通缉令。
