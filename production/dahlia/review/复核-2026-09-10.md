# 《黑色大丽花：消失的六天》复核记录（换机器复现 + 冻结帧定性）

日期：2026-09-10（在 Arena 沙箱里做，机器与云端出片的那台不是同一台）
对象：`交付/黑色大丽花_三分钟_带声音.mp4`（1920×1080 / 30fps / 5400 帧 / 180.011 秒）

这一轮不重出片，只回答两个之前悬着的问题：

1. **"混音换机器也能复现"这句话，有没有第二台机器验过？** —— 之前只有云端那一次测量。
2. **审片报的"35 处画面冻结"，到底几处是真缺陷？** —— 之前靠人工逐条判断，没量化。

结论：**1 有，逐位一致；2 零处真缺陷**。下面是数据。

## 一、换机器复现：不是"差不多"，是同一个数字

环境：Linux 6.1 x86_64 / Python 3.11.2 / **ffmpeg 7.0.2-static**（imageio-ffmpeg 的静态二进制，
与云端 runner 的发行版 ffmpeg 不是同一个构建）/ numpy 2.4.6 / pillow 12.3.0。

```bash
python3 production/dahlia/build_audio.py --work work/dahlia --output work/dahlia/soundtrack.wav
python3 production/review_film.py --film 交付/黑色大丽花_三分钟_带声音.mp4 \
    --project production/dahlia --work work/dahlia/review
```

这一步的意义：旧版混音是一条 ffmpeg 滤镜链（`loudnorm` 内部测量），换版本就换结果，
而**当时没有任何一道关卡会拦住"无声"**。把混音搬进 numpy 之后，同样的输入在另一台机器、
另一个 ffmpeg 构建上量出同一组数字——"复现"不再是一句声明。

现在这件事有回归测试守着：`production/tests/test_dahlia_mix.py` 会用仓库里真实的六段配音
重混一遍，与 `delivery/audio-report.json` 比对（容差 0.05 dB），漂移即失败。

## 二、35 处"冻结"：13 处是设计内的静帧，22 处是阈值误报，真缺陷 0 处

`review_film.py` 用 16×16 灰度签名找"1 秒内几乎没变"的片段，阈值 0.6/255 灰阶——
对慢速运镜的 AI 素材来说这个阈值太严，一审报了 35 处，人工逐条看才知道大部分是误报。

这次给工具加了**复核**：检出之后用 64×64 签名再量一次，取窗口内逐帧差的**中位数**
（不是最大值：静止画面里夹一次硬切，最大值能飙到 100+，会把信息卡误判成"有微动"）。

在参考片 35 个窗口上实测的两簇（`delivery/frozen-triage-calibration.json`）：

| 期望结论 | 窗口数 | 窗口内逐帧差中位数 |
|---|---|---|
| 真静止（graphic 信息卡 / archive 档案照 / 片尾卡） | 13 | 0.026 – 0.080 |
| 有微动（agnes 慢速运镜素材） | 22 | 0.210 – 1.7xx |

两簇之间是空的，阈值取 **0.15**，35 个窗口**零误判**。所以：

- 那 13 处本来就该静止（6 张资料卡 + 档案照片 + 片尾卡），不是缺陷；
- 那 22 处量得到持续微动，是慢速运镜被严阈值误判，不是渲染卡死；
- 复核后 `verdict` 字段写进 `review/film-review.json`，以后审片不用再人工逐条判断。

阈值是被测试钉住的：`test_review_film.py::test_threshold_sits_in_the_gap_measured_on_the_delivered_film`
要求它必须落在标定出的两簇之间，改坏就红。

## 三、黑帧：仍是 2026-09-09 记录的那 14 帧，没有新增

14 帧分布在片头淡入（0.00–0.03s）与片尾淡出（179.73–179.97s），其中 176.20s 有一帧
luma=0.0 的单帧黑闪（片尾暗卡接入处）。上一轮已记录，本轮复测位置一致，未做修改——
1/30 秒、肉眼不可察觉，改它要重出整片，收益不抵风险。

## 四、复核之后仍然没做完的事（没变，如实留着）

- **逐字听检**：本环境连不上 Hugging Face，faster-whisper 的模型下不来，做不了 ASR。
  "念的字与剧本一字不差"仍由「文本哈希绑定 + 语速正常 + 无缺音」间接支持。
- **四段字幕对轨覆盖率只有 0.13–0.72**（N01/N02/N03/N06 走的是停顿估算），需要人工听一遍。
- **构图、字幕错字、AI 画面畸变**：`review_film.py` 只能把抽样帧摆到人面前，判断仍要人看。
