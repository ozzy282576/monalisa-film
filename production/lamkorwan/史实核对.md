# 史实核对 ·《雨夜屠夫林过云：一卷菲林里的四条人命》

这份文件回答一个问题：**片子里每一句话，凭什么这么说。**
每一条都指到 `build_story.py` 的 `SOURCES` 里的公开报道；来源之间打架的地方，写清片子怎么处理的。

## 二、来源打架的地方，片子是怎么写的

| 有争议的点 | 不同说法 | 片中的处理 |
|---|---|---|
| 拘捕的日子 | 多数来源写 **八月十八日**；百度百科某个词条写「1982年8月17日」 | 片中只写 **八月十八日**（HK01、思考香港、求真百科、NOWnews 一致） |
| 冲印店在哪 | 报案地点有写**旺角**的，埋伏与拘捕地点有写**尖沙咀**的 | 片中统一说「尖沙咀一间相铺」（与拘捕现场一致），不写分店在旺角 |
| 发现照片的日子 | 有 8月10日（送放大）、8月16日（冲洗）等不同说法 | 片中说 **「一九八二年八月」**，不点具体日子 |
| 首名死者年龄 | 22 岁（多数）／21 岁（个别） | 用 **22 岁**（HK01、NOWnews、求真百科） |
| 首名死者的职业 | 舞女／夜总会大班／领班，各来源不一 | 片中**不写职业**，只写姓名与年龄 |
| 精神鉴定的结论 | 五名医生中「三位认为无精神病」「多数认为无精神病」 | 片中只写 **「五名精神科医生评估过他，陪审团不接受这个说法」**，不写几比几 |
| 死刑的形式 | 「判处绞刑」「依例判处死刑」 | 片中写 **「判处死刑」**，不写执行方式 |
| 是否已出狱 | 2018 年有网传假释，惩教署不评论；另有来源称长期监禁复核委员会不会假释 | 片中写 **「至今仍在服刑」**，并在事实边界里明确禁止「已释放／已出狱」的说法 |
| 是否还有更多受害者 | 有前记者称相片中判断出更多女性，但无法证实身份 | 片中**完全不提**，只说被起诉并定罪的**四条人命** |

## 三、与用户提交文案的差异（都在成片里改掉了）

用户提交的 40 镜脚本里，下面几处与公开来源对不上，成片按公开来源写：

1. 脚本「镜头 40」把结尾写成「1984 年，死刑被减免为终身监禁」——成片补上「**港督会同行政局**赦免死刑」这一层，与来源一致。
2. 脚本「镜头 19–21」写店员发现照片后「**立即**报警」，同时另一处写「警方让店员打电话叫他来取」；成片按来源写成**先报警 → 警方部署 → 由店员照常通知他来取相**，两条因果不冲突。
3. 脚本把冲印店写成「尖沙咀／旺角」两处；成片统一为**尖沙咀**。
4. 脚本 40 镜 × 4.5 秒 ≈ 180 秒；按工具链规格改为 **45 镜 × 4 秒 = 180 秒**（38 个 Agnes 动画镜头 + 7 张信息卡），每一镜只出现一次。
