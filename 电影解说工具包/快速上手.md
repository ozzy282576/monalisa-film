# 电影解说工具包 · 快速上手

> 做「几分钟讲完一部电影」解说视频的全自动流水线。
> 详细原理见同目录《电影解说剪辑制作手册.md / .txt》。本文件只讲怎么最快跑起来。

## 你只需要准备两样东西
1. **一条参考源视频**（别人剪好的同款解说 mp4，≥720p，10–25 分钟）
2. **一份解说稿 `narration.json`**：每句解说词 + 这句对应源视频的画面起止秒数
   （格式照抄 `示例-narration-惊唇劫.json`）

---

## 方式一：GitHub Actions 云端出片（推荐，不用装环境）

1. 把源视频切成 45MB 分块，放到 `production/new_source_parts/`，并写好 `manifest.json`
   （含 size、sha256、parts 列表；手册第 2 步有模板）。
2. 把写好的解说稿放到 `production/narration.json`。
3. 去 GitHub 仓库网页 → **Actions** 标签 → 选 **Build movie commentary** → 点 **Run workflow**。
4. 约 10 分钟后，在该运行页面底部 **Artifacts** 下载成片 mp4。

> workflow 模板见 `build-commentary.workflow.yml.txt`。
> 记得把里面的分支名、输出文件名改成你自己的。

## 方式二：本地出片

```bash
# 装依赖
pip install -r requirements.txt
# 另需系统安装 ffmpeg / ffprobe，以及中文字体(Linux: fonts-noto-cjk)

# 1) 拼回源视频（若用了分块存储）
cat production/new_source_parts/source.part-* > work/source.mp4

# 2) 自动切镜头
mkdir -p work/scenes output
scenedetect -i work/source.mp4 -o work/scenes detect-content -t 27 list-scenes -f scenes.csv

# 3) 一条命令渲染（配音+画面+字幕+配乐+混音全自动）
python render_commentary.py \
  --source work/source.mp4 \
  --scenes work/scenes/scenes.csv \
  --narration production/narration.json \
  --work work/production \
  --output "output/片名_10分钟电影解说_720p.mp4"
```

> ⚠️ 本地配音用 edge-tts，需能访问微软语音服务器（网络不通就用方式一）。

## 文件说明
| 文件 | 作用 |
|---|---|
| `render_commentary.py` | 核心渲染器（不用改，换片只调顶部参数） |
| `generate_horror_bgm.py` | 程序合成无版权悬疑背景音乐 |
| `align_reference_clips.py` | 参考片节奏测量（辅助） |
| `download_onedrive.py` | 从 git 分块拼回源视频并校验 |
| `upload_server.py` | 网页上传工具：浏览器传视频→自动切块进仓库 |
| `upload_text_server.py` | 网页上传区：拖 txt 文案→存进 `抖音文案/`（自动识别 GBK 等编码） |
| `build-commentary.workflow.yml.txt` | GitHub Actions 云端渲染模板 |
| `示例-narration-惊唇劫.json` | 解说稿格式范例（《惊唇劫》90 句成片所用） |
| `requirements.txt` | Python 依赖 |
| `电影解说剪辑制作手册.md/.txt` | 完整制作手册（原理+参数+排错） |

## 换新片要改的
- 源视频分块 + `manifest.json`
- `narration.json`（解说稿+画面时间码）
- 输出文件名
- （可选）配音声音 `VOICE`、画面裁切 `crop/pad` 参数 —— 见手册第 4、6 节
