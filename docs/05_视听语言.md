# 视听语言手册

## 1. 摄影
- **胶片**: 主线用 16mm Kodak 250D，颗粒粗，有1982年纪录片感。林过云的录像带用真正的1982年 Betamax 摄像机拍摄，4:3，自动曝光抽搐。
- **镜头语言**:
  - 林过云视角: 35mm，固定，后视镜构图，人物被框在框里。
  - 受害者视角: 手持，16mm，仰角，雨水在镜头上。
  - 明仔视角: 红光暗房，微距，药水气泡。
  - 何医生视角: 顶光，冷白，显微镜视角。
- **禁忌**: 禁止使用无人机俯拍尸体，禁止慢动作美化暴力。

## 2. 美术
- **颜色**:
  - 雨夜: 普鲁士蓝 + 钠灯橙 (王家卫《堕落天使》)
  - 暗房: 深红 + 药水黄
  - 法医室: 荧光灯绿 + 不锈钢银
  - 家: 80年代香港唐楼，绿墙、铁闸、佛龛
- **道具考据**:
  - 出租车: 1980年丰田 Crown，计程表是机械翻页式
  - 相机: Nikon FM2 + 闪光灯
  - 冲印店: Kodak 柯达纸袋，手动放大机，墙上贴“晒相一流”
  - 冰箱: 东芝双门，压缩机声大

## 3. 声音
- **雨**: 全片5.1声道，雨声分层：车顶雨、铁皮雨、伞面雨。杜比全景声。
- **收音机**: 林的车里永远是商台，1982年真实节目单：许冠杰《印象》、邓丽君《漫步人生路》。
- **静默**: 每次凶案后，有3秒绝对静音，只有冰箱嗡鸣。
- **配乐**: 不用交响乐。用1982年香港街头环境音采样 + 单簧管独奏 (参考《的士司机》) + 磁带卡带声。

## 4. 剪辑
- **平行剪辑**: 受害者上车 / 明仔洗照片 / 何医生写报告 三线并行，节奏由雨刷统一。
- **跳切**: 林的日记本，用跳切表现时间流逝与心理异化。
- **底片转场**: 用真实菲林烧片、划痕作为转场。

## 5. 参考影片
- 《分手的决心》(2022) - 凝视与物化
- 《十二宫》(2007) - 程序正义与日常
- 《利益区域》(2023) - 暴行在墙外，日常在墙内
- 《旺角卡门》(1988) - 雨夜香港
- 《驾驶我的车》(2021) - 车内空间作为心理空间

## 6. 海报概念
- 主海报: 雨夜出租车后窗，四个女孩的笑容重叠成蒙娜丽莎的轮廓，但细看是四张不同的证件照。
- 副标题: "Every girl just wanted to go home."
- 字体: 手写体“蒙娜丽莎” + 打字机字体“MONA LISA IN THE RAIN”
