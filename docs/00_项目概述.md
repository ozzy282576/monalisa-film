# 蒙娜丽莎的雨夜 / MONA LISA IN THE RAIN
## 林过云项目 - 电影企划总览

> **类型**: 心理惊悚 / 犯罪艺术片 / 新黑色电影  
> **时代**: 1982年 香港  
> **片名含义**: 凶手林过云痴迷摄影，将受害者称为他收藏的“蒙娜丽莎”。他试图在死亡中捕捉永恒的微笑，却只留下无法洗净的血色底片。
> **Logline**: 1982年雨季的香港，一名夜班出租车司机的底片在冲印店里显影，与此同时，一名被调离此案的女法医和一名冲印店学徒，在霓虹与暴雨中试图拼凑出那些被物化为“艺术品”的女性最后的声音。

### 项目愿景
本项目 **不是** 对《羔羊医生》等剥削式奇案片的重复。我们拒绝奇观化尸体与性暴力。

我们要拍的是：
1.  **关于“观看”的电影** - 摄影机、照相机、冲印机。谁在看？谁被看？当一个人把另一个人变成照片里的静物，暴力是如何发生的？
2.  **关于1982年香港的电影** - 廉政公署成立后的失序与秩序，公共屋邨的拥挤，夜班经济中女性的脆弱，柯达冲印店作为前数字时代唯一的“真相出口”。
3.  **关于被抹去的女性的电影** - 陈凤兰、陈云洁、梁秀云、梁惠心。她们不是“舞女”“收银员”“学生”的标签，她们是四个在雨夜里想要回家的人。

### 核心团队设定 (虚构)
- 导演: 以王家卫的城市孤独 + 奉俊昊的社会解剖 + 乔纳森·格雷泽《利益区域》的“日常中的邪恶”为参考
- 摄影: 16mm胶片 + 早期 Betamax 录像质感
- 美术: 1982年尖沙咀、土瓜湾、城门河实景复原
