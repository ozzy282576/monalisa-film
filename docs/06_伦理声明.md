# 伦理声明与创作底线

> 本项目涉及真实受害者，必须以最高伦理标准进行。

## 1. 我们为什么还要拍林过云？
1982年的案件已经被拍烂了，从《羔羊医生》到《神探大战》，林过云被塑造成猎奇符号。但四位女性 - 陈凤兰、陈云洁、梁秀云、梁惠心 - 她们的名字、笑容、梦想，从未被真正讲述。

我们拍，不是为了再消费一次凶手，而是为了回答：
- 为什么1982年，女性夜归只能依赖一辆陌生男人的车？
- 为什么2026年，类似结构仍在重复？
- 当照片可以被无限复制，女性的身体如何被物化为“收藏”？

## 2. 四不原则
1.  **不美化凶手**: 林过云不是天才，不是艺术家，是一个自卑、懦弱、将女性物化的普通人。拒绝给他任何魅力镜头。
2.  **不消费受害者**: 不拍摄任何受害者受害过程的裸露、尖叫、求饶。所有暴力在画外。
3.  **不虚构受害者隐私**: 四位女性的家庭、恋爱、工作细节均为虚构，但基于对1982年同阶层女性的社会学研究，已请教香港妇女劳工协会。
4.  **不提供犯罪教程**: 不详细展示分尸工具使用、电锯购买、抛尸地点精确坐标。剧本已请香港警方前重案组顾问审核，删除可模仿细节。

## 3. 家属与尊重
- 如项目进入制作，将尝试联系受害者家属 (如愿意)，听取意见，并设立“四位女性纪念基金”，将部分收益捐给香港关注夜班女性安全的NGO。
- 片尾字幕将打出：“本片受害者角色为虚构创作，但谨以此片纪念1982年雨夜中失去生命的四位女性。愿她们安息。”
- 拒绝使用任何真实案件现场照片、尸检照片。

## 4. 观众提示
- 成片将标注：本片包含对针对女性的暴力行为的讨论，可能引起不适。建议16岁以上观看。
- 放映时提供心理支持热线。
- 宣传物料中不出现任何血腥、裸露、分尸相关图像。

## 5. 创作团队自查清单
- [ ] 每一场戏问：这场戏是为了理解受害者，还是为了展示凶手？
- [ ] 每一个镜头问：如果受害者家属看到这个镜头，会感到被尊重还是被二次伤害？
- [ ] 每一句台词问：这句台词是否将女性简化为“舞女”“贪慕虚荣”？
- [ ] 每一处配乐问：是否在用音乐美化暴力？

## 6. 参考伦理框架
- 《利益区域》导演乔纳森·格雷泽：“我们不是要拍大屠杀如何发生，而是要拍它如何在日常中被忽视。”
- 香港电影分级制度：本片目标为 IIB (青少年及儿童不宜)，而非 III 级猎奇。
- 国际纪录片协会关于真实罪案改编的伦理指南。

> **最后一句**: 如果这部电影让观众记住的是四个女孩想回家的心情，而不是凶手的名字，我们就成功了。
