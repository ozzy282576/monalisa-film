# 三幕结构 / 90分钟版本

## 第一幕：雨季 (0-30min) - 建立世界与日常之恶

**开场 1982-02-03 凌晨4:17 雨**
- 黑屏，只有雨声、收音机杂音。
- 出租车仪表盘特写：空车牌亮着。雨刷节奏。
- 阿兰上车，浑身湿透，笑着说“师傅，土瓜湾贵州街”。林过云通过后视镜看她，不说话。
- 切到冲印店，明仔在暗房，红光。何医生在法医房，第一次解剖城门河浮尸，镜头只拍她的手套和报告纸。

**主题呈现**
- 阿兰失踪。母亲报警，警察说“舞女可能跟客走了”。
- 何医生被调离，她把阿兰的牙齿模型带回家。
- 林过云把车洗得很干净，买了一卷新菲林，写下日记：“第一个蒙娜丽莎，完成。”

**第一幕高潮**
- 5月29日，阿洁上车。同样雨夜，同样后视镜。林过云这次更熟练。
- 平行剪辑：明仔冲洗一对新人的婚纱照，新娘笑得很甜。阿洁在后座脱鞋，揉脚。
- 阿洁失踪后，便利店老板只说“她经常迟到”。

## 第二幕：显影 (30-70min) - 罪行升级与目击者觉醒

**A. 林的收藏癖**
- 林开始在家学习解剖，书是图书馆借的《人体解剖图谱》。
- 他买了玻璃罐，福尔马林。冰箱嗡鸣声越来越大。母亲抱怨电费贵。
- 阿云上车，她很健谈，甚至夸林车开得稳。林第一次感到被“看见”，反而更愤怒。
- 阿云反抗，后座留下抓痕。林用很长时间清理。

**B. 何医生的地下调查**
- 何医生私下联系三位失踪女性家属，发现共同点：雨夜、出租车、夜归。
- 她画了一张地图，用红笔连起四个地点，像蒙娜丽莎的轮廓。
- 她被上司警告：“你再搞，份工都冇。”

**C. 明仔的暗房**
- 7月2日，阿心上车，带着相机。两人聊摄影，林第一次笑。
- 阿心失踪后，学校老师以为她跟男友私奔。
- **中点 (50min)**: 林过云拿着第四卷菲林，走进柯达冲印店。明仔接过，写下单号：082-0717。
- 明仔进入暗房，红光下，照片浮现。第一张是阿心笑着比耶，第二张... 他手抖，药水洒了。
- 他冲出去找师傅，师傅看了一眼，说：“报警。”

**第二幕高潮**
- 便衣埋伏。林过云来取相，被捕。没有飞车，没有枪战，就在冲印店门口，雨刚停。
- 搜屋。警察打开冰箱。镜头不拍里面，只拍明仔在店里听到警笛声，何医生在实验室听到收音机新闻。
- 林过云在审讯室说：“我系艺术家。”

## 第三幕：定影 (70-90min) - 审判之后，雨过天晴？

**审判是画外音**
- 法庭戏我们只听声音，画面是四位女性生前的最后一天：
  - 阿兰在舞厅对镜练习微笑
  - 阿洁给女儿留菠萝包的纸条
  - 阿云拿到驾照那天摸方向盘
  - 阿心借相机时说“我想影低所有靓嘅嘢”

**何医生的完成**
- 何医生终于获准为四位死者做面部重建。她用黏土，一个一个捏出她们的笑容。
- 四个泥像并排放在窗前，阳光照进来，像四幅蒙娜丽莎。

**明仔的决定**
- 明仔把那卷底片的碎片冲进马桶后，去考了摄影学校。多年后，他成为一名专拍女性劳工的纪实摄影师。
- 最后一卷菲林，他拍的是1982年贵州街的天台，那里晾着四件连衣裙。

**结尾**
- 黑屏，雨声渐小。
- 字幕：四位受害者真实姓名。
- 最后镜头：1982年的香港雨夜，一辆空出租车亮着灯，慢慢开走，雨刷有节奏地摆动。车内收音机放着《雨丝情愁》，但没有乘客。
- 车开远，城市霓虹倒映在水洼里，像一幅被雨水打湿的蒙娜丽莎。
