# 人物小传

## 林过云 / 林过雨 (原型林过云) - 27岁
**饰演参考**: 早期梁朝伟的阴郁 + 秦昊的日常感，拒绝脸谱化变态

- 白天睡觉，晚上开的士。车是租的，房子是和父母、弟妹挤的。
- 极度自卑又极度自恋。认为自己是怀才不遇的艺术家，相机是他唯一的权力。
- 口头禅：“我系帮紧佢哋，佢哋做舞女/做夜班，唔系好嘢嚟。”
- 他的出租车收音机永远调在同一频率，副驾驶座位上放着一本《摄影入门》。
- **关键细节**: 他从不直视后座乘客的眼睛，只通过后视镜看。后视镜里的人是扁的、小的、可控制的。
- **弧光**: 从“惩罚坏女人”到“收藏美”，最后到恐惧——当照片被别人看到时，他第一次感到自己被观看。

## 何敏仪医生 (虚构，综合多位女法医) - 32岁
**饰演参考**: 吴君如 + 赵涛，专业、疲惫、愤怒

- 香港大学医学院毕业，法医科少有的女性。已婚，无子，丈夫是中学老师。
- 1982年2月，第一具城门河浮尸由她解剖。她写下报告：“死者为女性，20-25岁，死因机械性窒息，死后被分尸。”
- 上司以“影响不好，女仔唔好睇呢啲”为由将她调离此案，转去做交通意外。
- 她私下保留了四位死者的牙齿模型，试图用牙齿重建面容。
- **核心驱动**: 她要证明这些女孩不是“无名女尸”，她们有名字，有笑容。
- **名场面**: 她在实验室用黏土为阿兰重塑面部，最后轻轻给泥像点上嘴角的痣，像蒙娜丽莎。

## 明仔 / 张家明 (冲印店学徒) - 17岁
**饰演参考**: 柯震东 / 刘俊谦 少年感

- 中五毕业，没考上，家里安排到尖沙咀柯达冲印店做学徒。
- 梦想是去日本学摄影，墙上贴着《写真的日记》。
- 每天的工作是在暗房里把别人的记忆洗出来。他看过太多情侣合照，以为爱情就是那样。
- 1982年8月17日下午，他打开林过云那卷菲林。红光下，人脸浮现。
- **道德困境**: 师傅说“唔好多事，呢啲系客人私隐”。报警可能会丢工作，不报警会...
- **成长**: 从偷窥者变为目击者，最后成为唯一敢于作证的普通人。

## 四位女性 (群像，各有15分钟独立闪回，但由同一雨夜串联)

### 阿兰 (陈凤兰原型) - 22岁
- 油麻地舞厅领舞，梦想是去TVB艺员训练班。包里有一张皱巴巴的报名表。
- 上车前在电话亭和妈妈吵架：“我下个月就唔做啦！”
- 她的笑容是电影海报的原型 - 不是受害时的恐惧，而是她在舞厅试镜时，对着镜子练习的微笑。

### 阿洁 (陈云洁原型) - 31岁
- 深水埗24小时便利店收银，女儿6岁。离婚后独自抚养。
- 每晚5点下班，会给女儿带一个菠萝包。案发那天，菠萝包在出租车后座被压扁了。
- 她上车后第一件事是脱鞋，因为站了一整夜。

### 阿云 (梁秀云原型) - 29岁
- 酒楼洗碗，刚考到车牌，梦想是开小巴。
- 性格泼辣，上车后会和司机聊天，甚至会说“师傅你开车几好”。
- 她的反抗是最激烈的，雨刷的刮痕就是她留下的。

### 阿心 (梁惠心原型) - 17岁
- 刚考完中学会考，穿着校服去同学家拿笔记。书包里有相机，是问同学借来想学摄影的。
- 全片唯一一个和林过云聊摄影的人：“你部相机好靓啊。”
- 她的死让林过云第一次录像，因为他想“留住会欣赏他的人”。

## 配角
- **林母**: 沉默，在厨房切菜声很大，从不过问儿子房间的冰箱。
- **冲印店师傅**: 60岁，越战时做过随军摄影，见过太多，教明仔“有些相，唔洗出”。
- **重案组阿头**: 李修贤式探员，但疲惫，相信证据而非直觉。
